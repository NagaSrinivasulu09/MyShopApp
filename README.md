# 🛒 MyShop App

An Android e-commerce application built using **Jetpack Compose**, **Firebase**, and **Clean Architecture**.
The app allows users to browse products, add items, upload product images, and manage favorites.

---

## 🚀 Features

* 🔐 User Authentication (Firebase Auth)
* 🛍️ Add & View Products
* ❤️ Favorite Products (Room Database)
* ☁️ Image Upload (Cloudinary)
* 🔄 Real-time Data (Firestore)
* 📱 Modern UI using Jetpack Compose
* 🧭 Navigation with Compose Navigation

---

## 🏗️ Architecture

This project follows **Clean Architecture + MVVM**:

```
UI (Compose)
   ↓
ViewModel
   ↓
Repository
   ↓
Data (Firebase / Room / Cloudinary)
```

---

## 🧰 Tech Stack

* **Kotlin**
* **Jetpack Compose**
* **Firebase (Auth, Firestore, Storage)**
* **Room Database**
* **Retrofit**
* **Cloudinary (Image Upload)**
* **KSP (Room Compiler)**

---
